# AI Resume Screening System

An AI-based Resume Screening web application developed using Flask, HTML, CSS, JavaScript, and Python.

## Features

- Resume Upload
- PDF/DOCX Resume Parsing
- AI Skill Detection
- Candidate Information Extraction
- Suitable Job Role Prediction
- Resume Match Analysis
- Professional UI Design

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- pdfplumber
- python-docx

## How To Run

1. Install requirements

pip install -r requirements.txt

2. Run Flask app

python app.py

3. Open browser

http://127.0.0.1:5000
